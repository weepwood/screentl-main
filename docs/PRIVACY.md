# 隐私与数据处理说明

Screenshot Time-lapse 是本地优先工具。默认配置下，程序只截取屏幕并将图片保存到用户选择的本地目录。

## 默认关闭的能力

以下能力不会在首次运行时自动开启：

- 窗口标题采集。
- 前台应用名称采集。
- OCR 文字识别。
- 云端上传或远程分析。

项目代码中没有自动上传截图、视频、OCR 文本或配置的功能。

## 用户可配置的保护措施

- 按应用程序名称暂停截图。
- 按窗口标题关键词暂停截图。
- 锁屏时暂停。
- 用户空闲达到指定时间后暂停。
- 使用电池时暂停。
- 使用 `Ctrl+Alt+P` 立即切换全局隐私暂停。
- 在时间轴中排除、删除或遮挡敏感截图。
- 按天数或会话数量清理历史记录。

## OCR

OCR 只在用户主动开启时运行，并调用用户本机安装的 Tesseract。程序不会自动下载 OCR 模型，也不会将图片发送到网络服务。

## 数据位置

会话截图、缩略图和输出位于用户图片目录。SQLite 索引与配置位于 `%APPDATA%\ScreenshotTimeLapse`。删除数据库不会自动删除原始截图；删除会话时是否同时删除文件由用户操作决定。

## 使用边界

本工具面向用户记录自己的工作过程，不提供隐蔽采集、远程监控或绕过系统权限的能力。使用前应确保对被记录内容拥有合法权限，并遵守所在地区的隐私和劳动法规。
